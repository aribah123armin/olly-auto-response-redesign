# olly-auto-response-redesign
## Overview

This project is my solution to Olly's Product Design Challenge.

The challenge focused on improving the editing experience for AI-generated review responses while maintaining the speed and simplicity expected from an automated workflow.

## Problem

Users can currently modify generated responses only through preset action chips such as:

- Regenerate
- Make it Friendlier
- Make it Professional
- Add Contact Info

This limits user control and makes it difficult to apply specific edits.

## Proposed Solution

The redesign introduces:

- Freeform AI editing
- Natural language instructions
- Quick-edit suggestions
- Brand memory preferences
- Live response preview
- One-click AI modifications

The goal is to provide flexibility without increasing setup friction.
